QUEST TERMINAL — OFFLINE HASH GENERATOR

This page runs entirely in your browser (no network requests, no server). Use it to turn a plain-text code into the salted SHA-256 hash you paste into config.json, so the real code never appears in the app's source files. 

Result will appear here.

Copy the generated hash into the tag's codeHash field in config.json, and copy the salt into that tag's salt field.
